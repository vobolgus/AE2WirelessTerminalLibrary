# Беспроводной терминал

<ItemImage id="wireless_terminal" scale="4" />


Беспроводные терминалы — это портативные версии обычных проводных [терминалов](terminals.md). У них точно такие же интерфейсы,
как у проводных аналогов, только вместо слотов для предмета <ItemLink id="view_cell" /> в них слоты для [карт улучшения](upgrade_cards.md)

Чтобы привязать терминал к сети, вставьте его в правый верхний слот предмета <ItemLink id="wireless_access_point" />,
подключённого к этой сети. (Слот с изображением беспроводного терминала и стрелкой под ним)

Для работы они должны находиться в радиусе действия предмета <ItemLink id="wireless_access_point" />.

Их энергию можно восполнить в предмете <ItemLink id="charger" />.

# Беспроводной терминал

<ItemImage id="wireless_terminal" scale="4" />

Ваш обычный терминал, теперь портативный! Просматривайте содержимое [хранилища вашей сети](../ae2-mechanics/import-export-storage.md), обращайтесь к нему
и заказывайте предметы у своей системы [автокрафта](../ae2-mechanics/autocrafting.md) откуда угодно в радиусе действия предмета
<ItemLink id="wireless_access_point" />.
